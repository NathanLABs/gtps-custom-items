# GTPS Custom Items

Koleksi aset custom item (citem) untuk proyek Growtopia Private Server (GTPS), berisi tekstur RTTEX, ikon, animasi karakter, efek, kosmetik, tiles, dan renderer XML.

README ini mencakup seluruh koleksi, termasuk aset di direktori `BONUS/`. Aset utama dikelompokkan ke dalam folder sesuai nama citem atau paketnya; direktori `BONUS/` mempertahankan susunan aslinya. Semua aset tercatat dalam satu katalog, dengan satu README di direktori utama.

## Isi koleksi

| Jenis | Jumlah |
| --- | ---: |
| File tekstur `.rttex` | 235 |
| File renderer `.xml` | 11 |
| Total file aset | 246 |
| Kelompok nama dalam katalog citem | 65 |

Jumlah 65 adalah kelompok yang didata berdasarkan nama file, bukan jumlah pasti item di dalam game. Ikon, animasi, dan efek dengan nama yang sama dikelompokkan bersama. Texture sheet gabungan dapat berisi banyak item, sedangkan beberapa entri hanya memiliki ikon atau efek.

```text
.
|-- README.md
|-- Mario/
|   |-- mario_smh_idle.rttex
|   |-- mario_smh_jump_fall.rttex
|   |-- mario_smh_punch.rttex
|   `-- mario_smh_walk.rttex
|-- Akiha/
|   |-- akiha_2.xml
|   `-- *.rttex
|-- ...            Folder citem dan paket lainnya
`-- BONUS/
    `-- *.rttex    Susunan aset tambahan tetap seperti semula
```

## Aset gabungan dan pendukung

Selain katalog nama di atas, koleksi ini juga mencakup:

- **Texture sheet citem:** `ci1*`, `ci_n4`, `citemnibos22`, `custom_items*`, `enigma_custom_items1`, dan `gtfy_custom`.
- **Kosmetik:** `custom_cosmetics1*`, `brighver_custom_cosmetics1`, dan `mk4_custom_cosmetics1_icon`.
- **Senjata dan aksesori:** `swords*`, `custom_hand1*`, `custom_katanas`, `custom_sword1`, `custom_s*`, `custom_long*`, `custom_mps`, dan `custom_large`.
- **Aset kaki dan sepatu:** `custom_feet1*` dan `custom_shoes*`.
- **Tiles:** `custom_tiles*`, `customil_tiles3`, `brighver_custom_tiles3`, dan `tron_custom_tile1`.
- **Efek dan partikel:** `bju_dma`, `explosion`, `hand_partikel`, `particles*`, dan `realityps_particles2`.
- **Animasi pemain:** `player_horsepants_custom1` sampai `3` dan `player_sit_custom1` sampai `3`.
- **Aset antarmuka dan gambar pendukung:** `gui_wrench_customization`, `wrench_custom_tab`, dan `stre.icons`.

Nama di atas adalah nama dasar file `.rttex`; tanda `*` menunjukkan file pendamping dengan awalan yang sama. Paket gabungan belum memiliki pemetaan lengkap antara nama item, ID item, dan koordinat frame.

## Cara menggunakan

1. Unduh atau clone repository ini.
2. Pilih citem atau paket yang dibutuhkan, lalu ambil file tekstur beserta ikon, animasi, efek, dan XML pendampingnya jika tersedia.
3. Salin isi folder citem yang dipilih ke lokasi aset pada proyek Anda. Folder dalam repository digunakan untuk mengelompokkan file; referensi tekstur dalam XML tetap menggunakan path `game/<nama-file>.rttex`.
4. Hubungkan tekstur, koordinat frame, ikon, dan renderer ke definisi item pada proyek Anda. Repository ini menyediakan aset dan konfigurasi renderer; pendaftaran ID item serta konfigurasi server perlu disiapkan pada proyek yang memakai aset tersebut.
5. Periksa tampilan dan animasi di client, termasuk gerak, lompat, serangan, serta respawn jika didukung renderer.

### Catatan penggunaan

- Pertahankan ejaan dan huruf besar/kecil pada nama file, termasuk `neir.xml`, `kadio_hyb_idle.rttex`, `Fulguris.rttex`, dan `Mr_Debts.rttex`.
- Beberapa nama file muncul di lebih dari satu direktori. Khusus `custom_items2.rttex`, isi file di `Custom Items 2/` dan `BONUS/` berbeda; pilih paket yang sesuai sebelum menyalinnya ke lokasi yang sama.
- Enam renderer (`akiha_2.xml`, `kirito_2.xml`, `kula.xml`, `kuroyukihime.xml`, `mai_shiranui.xml`, dan `merkava_2.xml`) merujuk `game/particles9.rttex` untuk `TileStampData`. File tersebut tidak disertakan dalam koleksi; sediakan pada client atau sesuaikan referensinya.
